# Щоденник подорожей

Лабораторна робота №3, варіант 1.

## Запуск

Потрібен Node.js 22 або новіший.

```sh
npm ci
npm run dev
```

Перевірка TypeScript і production-збірка:

```sh
npm run build
```

## Сторінки

- `/` — стрічка з фільтрацією за міткою та сортуванням за датою початку.
- `/trips/:id` — повний запис, місця та галерея із заглушками фотографій.
- `/login` — навчальний вхід за нікнеймом.
- `/cabinet/new-trip` — додавання подорожі та посилань на фото.
- `/cabinet/profile` — редагування профілю.
- `/404` та невідомі адреси — сторінка 404.

Вхід зберігається у `sessionStorage` поточної вкладки. Пароль і серверна авторизація не використовуються. Подорожі та профіль зберігаються у `localStorage`. Початкові записи є прикладами для перевірки фільтрів і деталей. У формі можна вказати http/https посилання на фото, по одному в рядку. Без посилань або якщо зображення недоступне галерея показує заглушки, дозволені умовою.

Для перевірки: відкрити кабінет без входу, увійти, додати запис, знайти його у стрічці, перезавантажити сторінку та відкрити невідомий id. Під час виходу з незбереженої форми з’являється підтвердження.

Стек: Vue 3, TypeScript, Composition API, Vue Router, Pinia, Tailwind CSS 4, DaisyUI 5. На статичному хостингу потрібно налаштувати SPA fallback на `index.html`, щоб прямі посилання на вкладені сторінки працювали.
